# Retail Sales Analysis Using SQL

## Project Overview
This project focuses on analysing retail sales data using MySQL. The objective is to extract meaningful business insights about revenue, products, customers, monthly sales and payment methods.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Structure
The project contains four tables:

1. **Customers** – Customer details such as name, city, country and gender.
2. **Products** – Product names, categories, prices and stock.
3. **Orders** – Order dates, customer IDs and payment modes.
4. **Order_Details** – Products purchased, quantities and unit prices.

## Business Questions Answered
1. What is the total revenue?
2. How many units were sold?
3. How many orders were placed?
4. Which product category generated the highest revenue?
5. What are the top 5 products by revenue?
6. How does revenue vary by month?
7. Who are the top 5 customers by spending?
8. Which payment method is most commonly used?
9. Which products have no sales?
10. Which products have low stock?
11. Which orders have no order details?

## SQL Concepts Used
- SELECT and WHERE
- Aggregate functions: SUM, COUNT, AVG, MIN, MAX
- GROUP BY and HAVING
- ORDER BY and LIMIT
- INNER JOIN and LEFT JOIN
- Subqueries
- Aliases and calculated columns

## Project Files
- `retail_sales_database.sql` – Database structure and sample data.
- `retail_sales_analysis.sql` – SQL analysis queries.

## Conclusion
This project demonstrates practical SQL skills and the ability to answer common business questions using retail sales data.
